## 从 URL 到页面

当你在浏览器中输入 `https://example.com` 并按下回车时：

### 1. DNS 解析

```
浏览器 → 操作系统 DNS 缓存 → 路由器缓存 → ISP DNS → 递归 → 根域名 → 顶级域名 → 权威域名服务器
```

### 2. TCP 三次握手

```
客户端 (SYN, seq=x) ────────────→ 服务器
客户端 ←────── (SYN, seq=y, ACK, ack=x+1) 服务器
客户端 (ACK, seq=x+1, ack=y+1) ─→ 服务器
```

### 3. TLS 握手（HTTPS）

1. 客户端 Hello（TLS 版本、密码套件、随机字节）
2. 服务器 Hello + 证书（包含公钥）
3. 客户端验证证书，生成预主密钥
4. 双方推导会话密钥
5. 安全连接建立完成

### 4. HTTP 请求/响应

```
GET / HTTP/1.1
Host: example.com
Accept: text/html
Connection: keep-alive
```

## HTTP 缓存策略

```
┌─────────────┐
│   请求    │
└──────┬──────┘
       ▼
  ┌───────────┐  强缓存  ┌───────────┐
  │  缓存    │────fresh──→│ 使用缓存  │
  │ (max-age) │            └───────────┘
  └─────┬─────┘
        │ 过期
        ▼
  ┌───────────┐ 304      ┌───────────┐
  │  服务器   │──────────→│ 使用缓存  │
  │ (ETag /   │           └───────────┘
  │ Last-Mod) │ 200
  └───────────┘─────→ 更新缓存
```

**Cache-Control 头**：
- `max-age=31536000` — 缓存一年
- `no-cache` — 每次向服务器验证
- `no-store` — 永不缓存
- `public` / `private` — 谁可以缓存

## 现代协议

### HTTP/2
- 多路复用（单条 TCP 连接上多个流）
- 头部压缩（HPACK）
- 服务器推送
- 二进制分帧层

### HTTP/3
- 使用 QUIC（基于 UDP 而非 TCP）
- 消除队头阻塞
- 更快的连接建立（0-RTT）

## 状态码速查表

| 状态码 | 含义 |
|--------|------|
| 200 | 成功 |
| 301 | 永久重定向 |
| 304 | 未修改（缓存） |
| 400 | 错误请求 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 未找到 |
| 500 | 服务器内部错误 |
| 502 | 网关错误 |
| 503 | 服务不可用 |
