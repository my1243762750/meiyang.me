# mei-ui-system

**mei-ui-system** 不仅仅是一个 UI 库，更是一个**设计协议**，旨在确保跨平台和框架的绝对视觉一致性。

## 核心理念

该系统的核心理念是：UI 应该是一种**协议**，而不仅仅是一组样式。通过将值（Token）与实现（组件）分离，可以在任何地方部署统一的品牌标识。

- **Token 即真理**：所有视觉属性（颜色、间距、字体）都存储在平台无关的 JSON 文件中。
- **AI 优先工程**：专门设计了 `ai.md` 规则手册，指导 AI 代理生成完全符合设计系统的代码。
- **模式驱动密度**：超越静态间距，采用响应式密度模型，适配不同类型的产品（消息、分析、落地页等）。

## 技术实现

1. **多轴颜色系统**：双轴方法（蓝-紫）在保持可访问性的同时提供丰富的色彩。
2. **语义映射**：连接原始 HEX 值与功能性 UI 角色（如 `primary-500` → `bg-page`）。
3. **执行护栏**：包含严格的 `ai.md` 和 `patterns.md` 文档，防止硬编码并确保布局完整性。
