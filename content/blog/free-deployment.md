## 为什么需要部署？

你写了一个网页、一个 React 应用、一个 Vue 项目，想让别人通过网址访问它，而不仅仅是你在本地自己看。这就需要 **部署**——把你的文件放到一台服务器上，让互联网上的任何人都能访问。

好消息是：**前端项目（静态网站）部署几乎是成本最低的**，很多平台提供了慷慨的免费额度，甚至完全免费。

本文介绍 8 种免费部署方式，按从简单到强大排序。

---

## 1. Vercel

**推荐指数：⭐⭐⭐⭐⭐**

Vercel 是目前最流行的前端部署平台，也是 Next.js 框架的创建者。

**免费额度**：
- 100GB 带宽/月
- 无限项目数
- 自动 HTTPS（SSL 证书）
- 自定义域名支持
- **Git 推送即部署**——代码推送到 GitHub/GitLab，自动构建上线

**怎么用**：
```bash
# 1. 注册 vercel.com（用 GitHub 登录最简单）
# 2. 导入你的 GitHub 仓库
# 3. 点击 Deploy，完事
# 或者用 CLI
npx vercel
```

**适合**：React、Vue、Next.js、Nuxt 等几乎所有前端项目。

---

## 2. Netlify

**推荐指数：⭐⭐⭐⭐⭐**

Netlify 是 JAMstack 时代的先驱，功能和 Vercel 非常相似。

**免费额度**：
- 100GB 带宽/月
- 300 分钟构建时间/月
- 自动 HTTPS
- 自定义域名
- **Deploy Previews**——每个 Pull Request 自动生成预览链接

**怎么用**：
```bash
# 关联 GitHub 仓库，或者直接拖拽文件夹
npx netlify deploy --prod
```

**适合**：任何前端项目，特别是静态站点和单页应用。

---

## 3. Cloudflare Pages

**推荐指数：⭐⭐⭐⭐⭐**

Cloudflare 拥有全球最大的边缘网络（300+ 个节点），它的免费额度是业界最慷慨的。

**免费额度**：
- **无限带宽**
- 无限请求
- 无限站点
- 500 次构建/月
- 自动 HTTPS + HTTP/3 + QUIC
- 全球 CDN 加速

**怎么用**：
```bash
# 关联 Git 仓库，或使用 Wrangler CLI
npx wrangler pages deploy ./dist
```

**适合**：高流量站点、对访问速度要求高的项目、不想担心带宽超限的个人开发者。

---

## 4. GitHub Pages

**推荐指数：⭐⭐⭐⭐**

GitHub 官方提供的免费静态托管服务，和代码仓库深度绑定。

**免费额度**：
- 1GB 存储
- 100GB 带宽/月
- 每小时 10 次构建
- 自动 HTTPS
- 支持自定义域名

**怎么用**：
```bash
# 1. 在 GitHub 上创建一个仓库
# 2. 把你的 HTML/CSS/JS 推上去
# 3. 仓库 Settings → Pages → 选择 main 分支
# 4. 访问 https://你的用户名.github.io/仓库名
```

**适合**：个人博客、文档站点、项目展示页。跟 Git 工作流结合最紧密。

---

## 5. Surge.sh

**推荐指数：⭐⭐⭐**

命令行一键部署，简单粗暴。

**免费额度**：
- 一个自定义域名
- 自动 HTTPS
- **无需 Git**——直接上传文件

**怎么用**：
```bash
npm install -g surge
surge ./dist my-project.surge.sh
```

**适合**：快速原型、临时演示、不想折腾 Git 的场景。

---

## 6. Render

**推荐指数：⭐⭐⭐⭐**

Render 是一个现代化的全栈 PaaS 平台，对静态网站和 Web 服务都提供免费额度。

**免费额度**：
- 静态网站：免费（带宽和构建都免费）
- Web 服务：免费（但不活跃时会休眠）
- 自动 HTTPS
- Git 自动部署

**怎么用**：
```bash
# 关联 GitHub 仓库 → 选择 Static Site → 填写构建命令 → 部署
```

**适合**：静态网站、需要后端 API 支持的全栈项目。

---

## 7. Railway

**推荐指数：⭐⭐⭐⭐**

Railway 是一个更偏向全栈的平台，但部署前端也很方便。

**免费额度**：
- 30 天免费试用
- 之后 Hobby 计划 $5/月信用额度
- Git 自动部署
- 支持 Docker 和 Nixpacks

**适合**：前后端一体的项目，需要内置数据库（Postgres/Redis）的场景。

---

## 8. Coolify

**推荐指数：⭐⭐⭐**

Coolify 是一个**开源**的自托管平台，你可以在自己的服务器上搭建一个类似 Vercel 或 Heroku 的环境。

**费用**：
- 自托管：**完全免费**
- 需要一台云服务器（最便宜约 $5-6/月）
- 不需要额外付费给 Coolify

**怎么用**：
```bash
# 在自己的服务器上安装
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
# 然后通过网页界面关联 Git 仓库，一键部署
```

**适合**：有自己的服务器、对数据隐私有要求、想长期省钱的技术爱好者。

## 新手推荐路线

```
第一次部署
│
├── 选 Vercel（最简单，一步到位）
│   └── 用 GitHub 登录 → 导入项目 → Deploy
│
├── 或者 GitHub Pages（如果不想注册新账号）
│   └── 创建仓库 → 推送代码 → 开启 Pages
│
├── 想要全球访问快 → Cloudflare Pages
│
└── 想要纯静态展示页 → Surge（一行命令搞定）
```

无论选哪个，**都是免费的**。把项目部署上线，拿到一个可以给别人看的链接，这是前端开发者入门的必修课。
