## Overview

This is my personal knowledge base — a collection of everything I've learned and practiced as a frontend developer. It covers interview preparation, hands-on code implementations, and real-world project code.

## What's Inside

### Interview Preparation

Organized topic-by-topic with detailed notes and code examples:

- **JavaScript**: Promises, closures, prototypes, event loop, this binding, debounce/throttle
- **Vue**: Reactivity system, virtual DOM diff, component communication, Vue Router, Vuex
- **CSS**: Layouts (two/three column), centering, BFC, vertical-align, flexbox
- **HTTP**: TCP handshake, caching, status codes, security (XSS/CSRF)
- **Algorithms**: Binary trees, linked lists, sorting, hash tables

### Hands-On Implementations

Building things from scratch to understand them deeply:

- **Custom build tools**: Implementations of webpack, vite, rollup, and tapable hooks
- **State management**: Hand-written Vuex (v3/v4) and Vue Router
- **Server code**: Koa middleware, Express image server, SSE push
- **Utility functions**: Deep clone, phone validation, URL parsing, circular reference detection

### Production Projects

- **Browser Extensions**: TikTok video helper, CPD data helper for Edge
- **Vue Components**: File upload with progress, map integration with AMap
- **Performance**: Image optimization, lazy loading, FCP/LCP monitoring
